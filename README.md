# ChainXeno

ChainXeno implements a decentralized, node-optimized protocol for scalable transaction verification and network robustness.

ChainXeno is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ChainXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ChainXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
